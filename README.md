# Pixel Interpreter

Interpretador de uma linguagem própria que desenha pixel art numa grelha, desenvolvido em Kotlin com Jetpack Compose.

## Funcionalidades
- Editor de código integrado
- Abrir e gravar ficheiros `.pw`
- Validação de erros de compilação
- Execução passo a passo
- Comandos: Spawn, Cor, DrawLine, DrawCircle, DrawRectangle, Goto
- Variáveis, expressões aritméticas e saltos condicionais

## Exemplo

    Spawn(0, 0)
    Cor("Blue")
    DrawLine(1, 0, 5)

## Tecnologias
Kotlin, Jetpack Compose, Android Studio
